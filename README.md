
# 🛍️ Store

A full-stack e-commerce application built with React, Node.js,
Express.js and MySQL.

## 📸 Screenshots

![Home](./screenshots/home.png)

## ✨ Features



- 🔐 Authentication
- 👤 User & Admin roles
- 🛒 Shopping cart
- 📦 Order management
- 💳 Stripe payments
- 📊 Admin dashboard

## 🛠️ Technologies

- React
- Node.js
- Express.js
- MySQL
- Stripe
- Socket.IO
- JWT
- Cookie
- Nodemail

## 🚀 How to Run

### Application

```hash
git clone <YOUR_GIT_URL>
```

### Backend

```bash
cd backend
npm install
npm run dev
```
### Frontend

```bash
cd fronend
npm install
npm run dev
```
